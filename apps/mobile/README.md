# Polymath — mobile app (iOS + Android)

Expo SDK 58 / React Native 0.88 app with Expo Router native tabs.

```
src/app/            screens (Expo Router): tabs, reader, paywall, sign-in, category
src/components/     UI kit, cards, reader WebView, ad banner, brand
src/lib/            env, Supabase client, data access (repo), purchases (RevenueCat), ads (AdMob)
src/state/          app state: account, premium, credits, ownership, progress, settings
src/demo/           bundled sample library (generated by apps/admin `npm run content`)
plugins/            config plugin for Android release signing
```

```bash
npm install
cp .env.example .env          # optional — empty values = demo mode
npx expo run:ios              # or: npx expo run:android
npx expo start --web          # quick UI preview (ads/purchases simulated)
npm run typecheck && npm run lint
```

Native folders (`ios/`, `android/`) are generated by `npx expo prebuild` and not committed — configure native behaviour in `app.config.ts` and config plugins. Release builds are produced by the GitHub workflows (`.github/workflows/ios.yml`, `android.yml`). See the root [README](../../README.md) and [docs/SETUP.md](../../docs/SETUP.md).
